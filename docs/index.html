    Same offence same penalty?

    An open register of stewards' decisions. It reads the FIA's own documents, keeps every field's exact wording, runs each driver's penalty-points clock and lines up like with like. It never says a decision was wrong.

    01 · The ban clock

    05 · Checking the arithmetic

    The FIA prints a total. We add it up.

    Every decision that gives points prints the driver's new total. The register rebuilds that total from the decisions it holds. A match confirms the history. A gap has three possible causes it can't tell apart: missing earlier decisions (the usual one), a decision changed later, or a printed figure that's wrong. Gaps are shown, never patched.

      08 · Method and limits

      How it reads, where it stops.

      1. The parser quotes, it doesn't guess. Every decision is the same labelled table. Labels count only at the table's left edge and in order; each field keeps the exact characters it came from. Unfamiliar wording is flagged.
      2. The register watches the record. Each fetched PDF is hashed into an append-only chain, so a document the FIA replaces at the same address is recorded with both hashes.
      3. It can't say a decision was wrong. Two incidents under one article can differ in ways no table captures. Judging them is yours.
      4. Not much, yet. The hand-checked set is 14 decisions, picked by hand. Every group is a small sample until the full fetch runs.

      09 · Run it

      Standard library. Polite to the FIA.
